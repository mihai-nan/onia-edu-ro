1. Ce este NumPy și de ce îl folosim?

NumPy este biblioteca de bază pentru calcule științifice în Python. În IA, reprezentăm frecvent datele, imaginile, etichetele și parametrii unui model ca tablouri numerice.

În timp ce o listă obișnuită Python poate stoca obiecte eterogene, un ndarray are un tip de date comun și o formă explicită. Operațiile pot fi aplicate multor valori simultan, fără bucle Python scrise de fiecare dată. Această abordare se numește vectorizare.

Scoruri vectorizate 
import numpy as np
scoruri = np.array([7.5, 8.0, 9.5, 6.0])
print(scoruri.mean())
print((scoruri >= 8).sum())
Rezultat 
7.75
2

Metodele mean(), sum() și comparațiile booleene

O metodă NumPy, precum scoruri.mean(), se apelează pe tabloul scoruri. Metoda mean calculează media aritmetică: adună elementele și împarte suma la numărul lor. Nu modifică tabloul inițial.

1. Valorile și media aritmetică
7.58.09.56.0
mean = (7.5 + 8.0 + 9.5 + 6.0) / 4 = 31 / 4 = 7.75

scoruri.sum() ar fi 31, iar scoruri.size ar fi 4. De aceea scoruri.mean() este echivalent aici cu scoruri.sum() / scoruri.size.

Cum se evaluează expresia (scoruri >= 8).sum()?

Paranteza scoruri >= 8 nu produce un singur True sau False. NumPy verifică separat fiecare poziție și construiește un tablou boolean de aceeași formă. Elementele sunt de tip np.bool_.

PAS 1 · Vectorul de scoruri
7.589.56
→
PAS 2 · Condiția >= 8
FalseTrueTrueFalse
→
PAS 3 · Suma valorilor booleene2

False → 0, True → 1; suma este 0 + 1 + 1 + 0 = 2.

De ce funcționează?

Într-o sumă numerică, valorile booleene sunt tratate drept 0 și 1. Astfel, masca.sum() este numărul de elemente pentru care condiția este adevărată, echivalent cu np.count_nonzero(masca).

Selecție versus numărare

scoruri[scoruri >= 8] selectează valorile [8.0, 9.5]. În schimb, (scoruri >= 8).sum() returnează doar 2, nu aceste valori.

Experimentează: schimbă pragul de selecție

8
Utilitate în IA: calculul scorului mediu al unui model, numărarea exemplelor care depășesc un prag de încredere, numărarea predicțiilor corecte sau a pixelilor care satisfac o condiție.
Verifică dacă ai înțeles

Ce returnează (scoruri > 8).sum()? Răspuns: 1, deoarece doar 9.5 este strict mai mare decât 8. Diferența dintre > și >= este importantă.

Tipurile numerice: float32 versus float64

Numerele reale sunt stocate în virgulă mobilă. float32 utilizează 32 biți = 4 octeți per element, cu aproximativ 6–9 cifre zecimale semnificative. float64 folosește 64 biți = 8 octeți, cu aproximativ 15–17 cifre semnificative. Niciunul nu reprezintă exact toate numerele zecimale: de exemplu, valoarea 0.1 este aproximată.

MEMORIE PENTRU 1.000.000 DE ELEMENTE
float32 — 4 MB

1.000.000 × 4 octeți = 4.000.000 octeți

float64 — 8 MB

1.000.000 × 8 octeți = 8.000.000 octeți

MB reprezintă aici milioane de octeți; dispozitivele pot afișa și MiB.

Precizie aproximativă 7 cifre semnificative 16 cifre semnificative
Epsilon mașină ≈ 1.19 × 10⁻⁷ ≈ 2.22 × 10⁻¹⁶
Utilizare frecventă Tensori mari, rețele neuronale, GPU Calcule numerice unde eroarea de rotunjire contează
Avantaj / compromis Consum de memorie redus; precizie mai mică Precizie mai mare; memorie dublă
x32 = np.array([0.1, 0.2], dtype=np.float32) x64 = np.array([0.1, 0.2], dtype=np.float64) print(x32.itemsize, x64.itemsize) # 4 8 print(x32.nbytes, x64.nbytes) # 8 16 print(np.finfo(np.float32).eps) # ~1.19e-07
Cum alegem? Folosim adesea float32 în antrenarea rețelelor neuronale și pentru imagini/tensori mari, deoarece reduce memoria și poate accelera calculele pe GPU compatibile. Pentru calcul științific sensibil, acumulări lungi sau când sunt necesare erori de rotunjire mai mici, float64 este o alegere frecventă. Alegerea depinde și de algoritm, hardware și toleranța la eroare.

dtype este un atribut (fără paranteze), în timp ce mean() este o metodă. Alte tipuri: int32, int64, bool și uint8 (util pentru canale de culoare 0–255).

Verifică: ce înseamnă (2, 3, 4)?

Trei axe, 2 × 3 × 4 = 24 elemente. Poate reprezenta, de exemplu, două matrici de câte 3 rânduri și 4 coloane.

4. Indexare și slicing

Fiecare axă este indexată de la 0. Pentru o matrice, a[r, c] selectează elementul de pe rândul r și coloana c.

Indexare pe două dimensiuni

              [5, 6, 7, 8],
              [9, 10, 11, 12]])
print(a[1, 2])
print(a[:2, 1:3])
print(a[1, :].shape)
print(a[1:2, :].shape)
Rezultat 
7

 [6 7]]
(4,)
(1, 4)
EXPLICAȚIE PAS CU PAS

Slicing — evidențierea exactă a rândurilor și coloanelor

NumPy numără indicii de la 0. În matricea de mai jos, rândurile au indicii 0, 1, 2 și coloanele 0, 1, 2, 3. O expresie a[început:sfârșit] include începutul, dar exclude sfârșitul.

Selectează fiecare instrucțiune din exemplul dat

MATRICEA SURSĂ — GALBEN = CE ESTE SELECTAT

1. a[1, 2]

Rândul 1 este [5, 6, 7, 8]. Coloana 2 din acest rând conține 7. Rezultatul este un singur număr (np.int64 în mod obișnuit pe platformele cu întregi pe 64 de biți, dar tipul depinde de dtype).

2. a[:2, 1:3]

:2 → rândurile 0, 1; 1:3 → coloanele 1, 2. Rezultă [[2, 3], [6, 7]], o matrice 2 × 2.

3. a[1, :]

1 selectează un singur rând și îi elimină axa din rezultat; : înseamnă toate coloanele. Rezultatul are shape=(4,).

4. a[1:2, :]

1:2 reprezintă un interval de rânduri de lungime 1 și păstrează axa; rezultatul arată similar, dar are shape=(1, 4).

Indice întreg → reduce ndim cu 1 pentru axa selectată; interval de lungime 1 → păstrează axa.

Alte reguli importante: a[-1, :] este ultimul rând; a[:, ::2] selectează coloanele 0 și 2 (pas 2); a[::-1, :] inversează ordinea rândurilor. Sintaxa unui slice este start:stop:step.

În IA: accesarea unui pixel imagine[r, c], selectarea unui lot de observații X[:32, :] sau extragerea unor caracteristici X[:, 2:5].

Un indice întreg elimină axa selectată în rezultatul obișnuit: a[1, :] are forma (4,); un interval o păstrează: a[1:2, :] are forma (1, 4).

Operații numerice versus algebra matricială

În NumPy, operatorii +, -, *, / și ** sunt în general aplicați element cu element după regulile de broadcasting. În schimb, operatorul @ este un produs matricial, definit prin suma produselor corespunzătoare unei linii cu o coloană.

Compară rezultatele și explicațiile

x

y
56

Adunare: x + y

Poziție cu poziție: 1+5=6, 2+6=8, 3+7=10, 4+8=12. Ambele tablouri sunt 2 × 2.

Înmulțire: x * y

Fiecare element se înmulțește cu cel aflat în aceeași poziție: 1·5=5, 2·6=12, 3·7=21, 4·8=32. Acesta este produsul Hadamard.

Produs matricial: x @ y

Elementul de pe rândul 0, coloana 0: 1·5+2·7=19; pentru poziția (0,1): 1·6+2·8=22. Similar rezultă 43 și 50 pe linia a doua.

Transpunere: x.T

Rândurile devin coloane, astfel că [[1,2],[3,4]] se transformă în [[1,3],[2,4]]. Operația este utilă la produse matriciale și prelucrarea caracteristicilor.

Pentru A cu forma (m, n) și B cu forma (n, p), produsul A @ B are forma (m, p); elementul (i, j) este suma A[i,k] × B[k,j] pentru k = 0...n−1.

7. Agregări și parametrul axis

Cu axis alegi axa eliminată prin agregare: pe o matrice, axis=0 agregă pe rânduri (rezultat pe coloane), iar axis=1 agregă pe coloane (rezultat pe rânduri).

Agregări pe axe 
a = np.array([[1, 2, 3],
              [4, 5, 6]])
print(a.sum())
print(a.sum(axis=0))
print(a.sum(axis=1))
print(a.mean(axis=0))
print(a.argmax(axis=1))
Rezultat 
21
[5 7 9]
[ 6 15]
[2.5 3.5 4.5]
[2 2]

Ce înseamnă cu adevărat axis=0 și axis=1?

Metodele de agregare transformă mai multe valori într-o statistică: sumă, medie, minim, maxim, abatere standard etc. Pentru un tablou de două dimensiuni, axis=0 reduce axa rândurilor și păstrează câte un rezultat pentru fiecare coloană; axis=1 reduce axa coloanelor și păstrează câte un rezultat pentru fiecare rând. Fără axis, agregarea folosește toate elementele.

argmin(), argmax() Poziția (indicele) unui minim/maxim. Cu axis=1, argmax dă [2, 2] în exemplu. Identificarea clasei cu cel mai mare scor (argmax).
var() Varianța populației: media pătratelor abaterilor față de medie. Măsurarea dispersiei valorilor.
std() Abaterea standard: rădăcina pătrată din varianță; implicit ddof=0. Standardizarea caracteristicilor numerice.
median() Mediana, prin np.median(a) (nu a.median()). Statistică mai robustă la valori extreme.
count_nonzero() np.count_nonzero(a > 3) = 3. Numărarea elementelor care respectă o condiție.

Pentru vectorul v = [2, 4, 6], media este 4, abaterile sunt [-2, 0, 2], pătratele lor [4, 0, 4], iar varianța populației este 8/3 ≈ 2.667. Abaterea standard este √(8/3) ≈ 1.633.

La standardizare, scădem din fiecare valoare media caracteristicii și împărțim la abaterea standard a acesteia. Dacă abaterea este 0 (toate valorile sunt egale), împărțirea trebuie tratată separat.

Regula formelor, explicată prin matrice colorate

Broadcasting înseamnă că NumPy interpretează o dimensiune de lungime 1 ca fiind repetată, fără să fie necesară construirea explicită a copiilor. Formele sunt comparate de la dreapta la stânga; fiecare pereche de dimensiuni trebuie să fie egală sau una dintre ele să fie 1.

MATRICEA A: shape = (3, 2)

Vectorul se aliniază cu ultimul ax al matricei.

Alege o situație: repetare pe rânduri, pe coloane sau incompatibilitate

(3, 2) + (2,) → (3, 2)
(3, 2) + (3, 1) → (3, 2)
(4, 3) + (4,) → eroare, fiindcă ultimele dimensiuni 3 și 4 sunt incompatibile.

Un mod rapid de a verifica este să completezi cu 1 dimensiunile care lipsesc în stânga. De exemplu, (2,) se poate privi ca (1, 2). Repetarea se face logic pe prima dimensiune, obținând (3, 2).

În IA: adăugarea unui vector de bias la fiecare observație, centrare prin scăderea mediilor pe coloane și ajustarea canalelor unei imagini.

NumPy compară dimensiunile de la dreapta la stânga. Două dimensiuni sunt compatibile dacă sunt egale sau una dintre ele este 1. Dimensiunile absente sunt considerate 1. Dacă regula nu poate fi respectată, se produce o eroare de formă.

Forme Forma rezultatului Compatibile?
(4, 3) + (3,) (4, 3) Da
(3, 1) + (1, 4) (3, 4) Da
(4, 3) + (4,) — Nu
De ce este important pentru IA
Broadcasting evită de multe ori folosirea lui np.tile(). Acest lucru simplifică expresiile și reduce nevoia de copii intermediare.

Aceleași 12 valori, forme diferite

reshape schimbă modul de grupare a valorilor în axe, nu valorile în sine. Ordinea implicită este pe rânduri (C-order). Trebuie să se păstreze numărul total de elemente: 12 = 3 × 4 = 2 × 6 = 4 × 3. Argumentul -1 poate deduce automat o singură dimensiune.

Construiește 3 rânduri, fiecare cu 4 elemente. Rezultatul are două axe și 12 elemente.

reshape(-1)

Transformă structura într-un vector cu 12 elemente; unicul -1 este calculat automat.

b.T

Schimbă axele: o matrice de formă (3,4) devine (4,3). Valorile nu mai sunt grupate la fel ca în reshape(4,3).

Adaugă o axă de lungime 1: (3,4) devine (3,4,1). Numărul de valori rămâne 12.

np.newaxis (sau None) introduce o axă de lungime 1. Este util pentru a adapta formele intrărilor unor modele sau pentru a controla broadcasting-ul.

Sortare pe axe, indici de sortare și logică booleană

np.sort(a, axis=1) sortează independent fiecare rând (axa 1), în timp ce np.argsort(a, axis=1) returnează indicii pozițiilor originale care ar produce acea ordine. np.any și np.all sunt agregări logice aplicate măștilor booleene.

De unde rezultă [1, 2, 0]?

Primul rând este [9, 2, 7]: 2 se află la indicele 1, 7 la indicele 2, 9 la indicele 0. Așadar argsort oferă [1, 2, 0].

any versus all

Pentru masca a > 8, există un True (9), deci any este True. Pentru a > 0, toate valorile sunt pozitive, deci all este True.

În Computer Vision, o imagine color este adesea reprezentată printr-un tablou de formă (înălțime, lățime, 3), cele trei canale fiind R, G și B.

O imagine este un tablou cu trei axe

Un pixel al unei imagini RGB are trei componente: roșu (R), verde (G), albastru (B). Într-un tablou uint8, fiecare componentă are valori întregi între 0 și 255. Pentru un tablou cu forma (4, 5, 3), avem 4 rânduri × 5 coloane × 3 canale = 60 valori, adică 60 de octeți de date brute (fără metadate).

Interpretarea indicilor

imagine[r, c, 0] este componenta R a pixelului (r,c); imagine[r,c,1] pentru G și imagine[r,c,2] pentru B.

imagine[:, :, 0] = 255 face toate componentele roșii egale cu 255, fără să schimbe canalele G și B.

axa 0 = înălțime (4 rânduri)
axa 1 = lățime (5 coloane)
axa 2 = canale (3 componente).

12. Aplicații practice și recapitulare

Operațiile de mai sus formează baza etapelor de preprocesare a datelor numerice, normalizare și calcul matricial din învățarea automată.

Scorul unui clasificator liniar 
import numpy as np
X = np.array([[1.0, 2.0], [2.0, 1.0], [4.0, 3.0]])
w = np.array([0.6, -0.2])
b = 0.5
scoruri = X @ w + b
print(scoruri.round(2))
print((scoruri >= 1.0).astype(int))
Rezultat 
[0.7 1.5 2.3]
[0 1 1]
EXPLICAȚIE PAS CU PAS

Un exemplu complet de clasificare: de la matrice la etichete

Un clasificator liniar atribuie fiecărei observații un scor calculat ca produs scalar între caracteristici și ponderi, urmat de adăugarea biasului: s = x₁w₁ + x₂w₂ + b. În exemplul de mai sus avem ponderile w=[0.6,-0.2] și termenul liber b=0.5.

SCORURI CALCULATE MANUAL PENTRU FIECARE OBSERVAȚIE
Observația 0 · [1, 2]
1·0.6 + 2·(-0.2) + 0.5 = 0.7
Observația 1 · [2, 1]
2·0.6 + 1·(-0.2) + 0.5 = 1.5
Observația 2 · [4, 3]
4·0.6 + 3·(-0.2) + 0.5 = 2.3

Formula X @ w calculează simultan toate produsele scalare, pentru că X.shape=(3,2) și w.shape=(2,). Rezultatul are forma (3,), iar +b adaugă constanta 0.5 fiecărui scor.

Schimbă pragul și urmărește predicțiile

1.0

La pragul 1.0, condiția scoruri >= 1.0 este [False, True, True], iar .astype(int) transformă masca în [0, 1, 1]. Observă că astype(int) convertește valori; nu calculează probabilități.

scoruri = X @ w + b # [0.7 1.5 2.3] masca = scoruri >= 1.0 # [False True True] etichete = masca.astype(int) # [0 1 1] numar_pozitive = masca.sum() # 2
Atenție: scorul liniar nu este automat o probabilitate. Pentru probabilități în clasificarea binară se poate aplica o funcție precum sigmoid, în cadrul unui model adecvat. Un prag diferit poate schimba deciziile fără a modifica scorurile inițiale.
Exercițiu final: dacă pragul devine 2, câte observații sunt pozitive?

Este selectată numai observația 2, cu scorul 2.3. Masca este [False, False, True], etichetele sunt [0, 0, 1], iar numărul de predicții pozitive este 1.

În acest exemplu, X conține trei observații și două caracteristici. Vectorul w conține ponderile, iar b reprezintă termenul liber. Calculul tuturor scorurilor se face într-o singură expresie vectorizată.
