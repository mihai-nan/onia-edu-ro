1. Ce este Pandas?

Pandas este o bibliotecă Python pentru analiza și prelucrarea datelor tabelare, cu facilități de import/export în CSV, JSON, Excel și alte formate.

Două structuri sunt centrale: Series (o coloană, cu valori și etichete de index) și DataFrame (un tabel bidimensional cu rânduri și coloane). Un DataFrame poate conține coloane de tipuri diferite.

Series și DataFrame
import pandas as pd
s = pd.Series([1.2, 1.4, 1.1], name="pret")
df = pd.DataFrame({"oras": ["București", "Cluj", "Iași"],
                   "scor": [0.91, 0.88, 0.86]})
print(s.mean())
print(df.shape)
Rezultat
1.2333333333333334
(3, 2)

2. Importul și exportul fișierelor CSV

CSV este un fișier text care reprezintă datele sub formă de rânduri și câmpuri delimitate; Pandas îl citește de obicei cu read_csv().

Citire și export CSV
import pandas as pd
# Fișierul este inclus în proiect
avocado = pd.read_csv("datasets/avocado.csv", index_col=0)
print(avocado.shape)
print(avocado.columns[:4].tolist())
avocado.head(3).to_csv("primele_trei.csv", index=False)
Rezultat
(18249, 13)
['Date', 'AveragePrice', 'Total Volume', '4046']

index_col=0 folosește prima coloană ca index. Dacă nu dorești să salvezi indexul în fișierul de ieșire, treci index=False la to_csv(). Astfel eviți apariția unor coloane suplimentare de index la importuri succesive.

Adaptare pentru portabilitate

3. Primele observații și caracteristicile tabelului

În practică, după import verificăm dimensiunea, tipurile, valorile lipsă și distribuția aproximativă a coloanelor.

Inspecția inițială
print(avocado.shape)
print(avocado.head())
print(avocado.tail(3))
avocado.info()
print(avocado.describe())

head(n) afișează primele n observații; tail(n) afișează ultimele n. info() rezumă coloanele, tipurile și valorile nenule. describe() calculează statistici descriptive pentru coloanele numerice.

04

4. Selectarea coloanelor, loc și iloc

Selectezi o coloană printr-un nume, mai multe coloane printr-o listă, iar elementele prin loc sau iloc.

Selectare prin etichetă sau poziție
preturi = avocado["AveragePrice"]
selectie = avocado[["AveragePrice", "Total Volume"]]
print(preturi.head(2))
print(selectie.iloc[:3, :])
print(avocado.loc[0, "AveragePrice"])

loc folosește etichetele rândurilor și coloanelor; iloc folosește pozițiile întregi. Nu confunda indexul numeric folosit ca etichetă cu poziția elementului.

5. Filtrarea pe baza condițiilor

Condițiile se evaluează pe fiecare rând și produc o mască booleană folosită pentru selectare.

Filtrare pe criterii multiple
atlanta = avocado[avocado["region"] == "Atlanta"]
organic_ieftin = avocado[
    (avocado["type"] == "organic") &
    (avocado["AveragePrice"] < 1.02)
]
regiuni = avocado[avocado["region"].isin([
    "Atlanta", "Columbus", "SouthCentral"
])]
print(len(organic_ieftin), len(regiuni))
Capcană frecventă
Pentru serii Pandas folosește & și | între condiții, punând fiecare comparație între paranteze. Operatorii Python and/or nu sunt potriviți pentru combinarea element-cu-element a seriilor.

6. Indexul DataFrame și datele calendaristice

Un index bine ales simplifică prelucrările, în special pentru serii temporale.

Date calendaristice și index
avocado["Date"] = pd.to_datetime(avocado["Date"])
pe_date = avocado.set_index("Date")
print(pe_date.index.dtype)
refacut = pe_date.reset_index()
print(refacut.columns[0])
Rezultat
datetime64[ns]
Date

set_index() stabilește noul index, iar reset_index() readuce un index obișnuit. Conversia cu pd.to_datetime() este necesară deoarece un CSV nu descrie automat semantica fiecărui câmp.

7. Sortarea și construirea de coloane noi

Sortarea poate folosi valorile unei coloane sau etichetele indexului. Coloanele noi pot fi obținute prin calcule vectorizate.

Sortare și transformări
ordonat = avocado.sort_values("AveragePrice", ascending=False)
cronologic = pe_date.sort_index()
avocado["Volum_mii"] = avocado["Total Volume"] / 1000
print(ordonat["AveragePrice"].head(3).tolist())

Pentru eliminarea unei coloane folosește drop(columns=[...]). Operațiile fără inplace=True întorc, de regulă, un obiect nou; este preferabil să atribui explicit rezultatul.

8. Statistici și agregări cumulative

Valorile numerice pot fi sumarizate prin minim, maxim, medie, mediană sau sumă, iar cumsum() calculează sumele cumulative.

Statistici uzuale
print(avocado["AveragePrice"].mean())
print(avocado["AveragePrice"].median())
print(avocado["Total Volume"].cumsum().head(3))

O medie cumulativă sau o sumă cumulativă exprimă istoricul până la rândul curent. Pentru serii temporale, sortează întâi după dată, astfel încât interpretarea cumulului să fie corectă.

9. Gruparea și agregarea datelor

Cu groupby() poți obține rapid statistici pentru fiecare regiune, tip de avocado sau dată.

GroupBy pe una sau mai multe coloane
medii = avocado.groupby("region")["AveragePrice"].mean()
volume = avocado.groupby(["region", "type"])["Total Volume"].sum()
statistici = avocado.groupby("region")["AveragePrice"].agg(
    ["count", "mean", "median", "max"])
print(medii.head(3))

O grupare urmează logica split → apply → combine: datele sunt despărțite în grupuri, asupra fiecărui grup se calculează o statistică, apoi rezultatele sunt reunite. Este o operație centrală în analiza exploratorie.

10. Vizualizări în Pandas

Pandas poate folosi Matplotlib pentru grafice cu bare, linii, histograme și diagrame de dispersie.

Grafice cu bare și scatter
import matplotlib.pyplot as plt
volum_regiuni = avocado.groupby("region")["Total Volume"].sum()
volum_regiuni.plot(kind="bar", figsize=(11, 5))
plt.tight_layout()
plt.show()

avocado.plot(x="Total Volume", y="AveragePrice",
             kind="scatter", figsize=(8, 5))
plt.show()

11. Medii mobile și serii temporale

O medie mobilă atenuează fluctuațiile și evidențiază tendința unei serii; fereastra stabilește câte observații intră în calcul.

Fereastră mobilă de 14 observații
avocado["Date"] = pd.to_datetime(avocado["Date"])
atlanta = avocado[
    (avocado["region"] == "Atlanta") &
    (avocado["type"] == "conventional")
].sort_values("Date")
atlanta["medie_mobila_14"] = (
    atlanta["AveragePrice"].rolling(window=14).mean()
)
De reținut
Începutul unei serii cu rolling(14) are implicit 13 valori NaN, fiindcă nu există încă suficiente observații pentru o fereastră completă. Poți controla acest comportament prin min_periods.

12. Identificarea și tratarea valorilor lipsă

Datele reale pot avea celule necunoscute. Pandas reprezintă frecvent aceste valori prin NaN sau pd.NA, în funcție de tip.

Valori lipsă: isna, dropna, fillna
lipsa = avocado.isna().sum()
print(lipsa[lipsa > 0])
fara_lipsa = avocado.dropna()
completat = avocado.fillna({"AveragePrice": 0})

isna() produce o mască booleană. Prin isna().sum() obții numărul de valori lipsă per coloană. Eliminarea sau completarea trebuie justificată în funcție de semnificația datelor: înlocuirea arbitrară cu zero poate introduce erori statistice.

13. Codificarea caracteristicilor categoriale

Modelele de machine learning folosesc în general reprezentări numerice; de aceea, valorile de tip categorie trebuie codificate.

One-hot encoding
etichete = pd.DataFrame({
    "tip": ["organic", "conventional", "organic"]
})
encodat = pd.get_dummies(etichete, columns=["tip"], dtype=int)
print(encodat)
Rezultat
   tip_conventional  tip_organic
0                 0            1
1                 1            0
2                 0            1

Codificarea one-hot creează câte o coloană binară pentru fiecare categorie. Materialul sursă compară această abordare cu atribuirea unui număr întreg fiecărei clase (label encoding). Alegerea codificării depinde de model și de natura atributelor.
