Vizualizarea datelor cu Matplotlib și Seaborn

De la construirea unei figuri și alegerea unui tip de grafic la explorarea distribuțiilor, corelațiilor și curbelor de învățare. Exemple Python explicate, imagini generate local și aplicații în inteligența artificială.

Obiectiv: să citești critic și să construiești grafice corecte și reproductibile pentru date de antrenare și evaluare.
01

1. De ce vizualizăm datele?

Un grafic nu este doar o imagine atractivă: este o metodă de explorare, verificare și comunicare a proprietăților datelor.

În pregătirea pentru ONIA, vizualizarea apare la explorarea datelor înainte de antrenare (exploratory data analysis, EDA), la compararea claselor, la monitorizarea funcției de pierdere și la interpretarea predicțiilor. Python folosește frecvent Matplotlib pentru controlul detaliat al figurilor și Seaborn pentru reprezentări statistice bazate pe tabele Pandas.

Evoluție în timpLinie · plot
Relația a două valoriDispersie · scatter
Comparație categoriiBare · bar
Distribuție numericăHistogramă · hist
Comparație distribuțiiBoxplot · boxplot
CorelațiiHeatmap · heatmap
Principiu esențial
Alege tipul graficului în funcție de întrebarea la care vrei să răspunzi, nu doar după aspectul lui. Graficele pot induce în eroare dacă axe, unități, legende sau selecția datelor sunt greșite.
02

2. Matplotlib: Figure, Axes și pyplot

Înțelegerea structurii unei figuri face codul mai ușor de extins la mai multe grafice.

Figure este întreaga suprafață a imaginii; un obiect Axes reprezintă regiunea în care desenăm un grafic și deține axele, etichetele, legenda și titlul. pyplot este o interfață convenabilă importată uzual ca plt.

Primul grafic cu interfața orientată pe obiecte
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [2, 4, 3, 7, 8]

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(x, y, marker="o", label="Scor")
ax.set_title("Evoluția scorului")
ax.set_xlabel("Epocă")
ax.set_ylabel("Scor")
ax.grid(alpha=0.3)
ax.legend()
plt.show()

Metoda fig, ax = plt.subplots() este recomandată pentru majoritatea exercițiilor: obiectul ax indică explicit unde ajunge fiecare element. Varianta scurtă plt.plot(...) este utilă pentru demonstrații simple, dar devine mai dificil de gestionat în proiecte mari.

03

3. Grafice liniare: evoluția antrenării

O linie conectează observații într-o ordine semnificativă: timp, epoci, iterații ori valori ale unui parametru.

Două curbe pe același Axes
import numpy as np
import matplotlib.pyplot as plt

epoci = np.arange(1, 21)
pierdere_train = 0.94 * np.exp(-epoci / 6) + 0.09
pierdere_valid = (0.76 * np.exp(-epoci / 7.5) + 0.13
                  + np.maximum(epoci - 12, 0)**1.5 * 0.008)

fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(epoci, pierdere_train, label="Antrenare", marker="o")
ax.plot(epoci, pierdere_valid, label="Validare", marker="s")
ax.set(xlabel="Epocă", ylabel="Pierdere", title="Curbe de învățare")
ax.legend()
ax.grid(alpha=0.3)
plt.show()
Interpretare în IA
Dacă pierderea de antrenare scade, iar cea de validare începe să crească, graficul poate indica overfitting. Un singur grafic nu demonstrează automat cauza; verifică și datele, metrica și protocolul experimental.
04

4. Scatter: relația dintre două caracteristici

Fiecare punct reprezintă o observație; spre deosebire de linie, punctele nu sunt conectate automat.

Scatter cu puncte transparente
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(21)
x = rng.uniform(1, 10, 60)
y = 0.65 * x + 1 + rng.normal(0, 1.1, 60)

fig, ax = plt.subplots()
ax.scatter(x, y, alpha=0.8, s=45)
ax.set(xlabel="Caracteristica X", ylabel="Caracteristica Y")
plt.show()

Argumentul alpha controlează transparența, s mărimea punctelor, iar c culoarea. În clasificare, colorarea punctelor după etichetă poate evidenția clase separate sau suprapuse.

05

5. Bare: compararea claselor și dezechilibrul datelor

Graficele cu bare sunt potrivite pentru cantități asociate unor categorii discrete.

Grafic cu bare
import matplotlib.pyplot as plt

etichete = ["pisică", "câine", "pasăre"]
frecvente = [64, 29, 12]

fig, ax = plt.subplots()
ax.bar(etichete, frecvente)
ax.set(title="Distribuția claselor", ylabel="Număr exemple")
plt.show()

În IA, un set de date dezechilibrat poate necesita atenție la alegerea metricilor de evaluare și la împărțirea în loturi. Nu confunda barele (categorii) cu histograma (valori numerice grupate în intervale).

06

6. Histograme: distribuția valorilor și alegerea intervalelor

O histogramă grupează valori numerice în intervale (<em>bins</em>) și arată câte observații apar în fiecare interval.

Histogramă și marcarea mediei
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(21)
scoruri = rng.normal(loc=70, scale=11, size=600)

fig, ax = plt.subplots()
ax.hist(scoruri, bins=20, edgecolor="white")
ax.axvline(scoruri.mean(), color="crimson", linestyle="--",
           label="Media")
ax.set(xlabel="Scor", ylabel="Frecvență")
ax.legend()
plt.show()

Numărul de intervale influențează rezoluția: prea puține pot ascunde forme interesante; prea multe pot transforma distribuția într-un desen zgomotos. Pentru comparații între seturi de dimensiuni diferite, analizează și opțiunea density=True.

07

7. Boxplot și violin plot: variabilitate și valori extreme

Media singură nu explică dispersia scorurilor; reprezentările distribuțiilor arată unde se concentrează observațiile.

În boxplot, linia din dreptunghi reprezintă mediana; cutia acoperă intervalul dintre quartilele Q1 și Q3. Mustățile reprezintă de obicei valorile din limita de 1,5 × IQR, iar punctele externe sunt candidați pentru valori atipice, nu neapărat erori. Un violinplot adaugă distribuția estimată a densității.

Comparația modelelor cu Seaborn
import seaborn as sns
import pandas as pd
import matplotlib.pyplot as plt

scoruri = pd.DataFrame({
    "Model A": [0.74, 0.80, 0.79, 0.82, 0.85, 0.76],
    "Model B": [0.67, 0.78, 0.86, 0.88, 0.91, 0.92]
})

fig, ax = plt.subplots()
sns.boxplot(data=scoruri, ax=ax)
ax.set(ylabel="Acuratețe", title="Dispersia scorurilor")
plt.show()

8. Mai multe grafice în aceeași figură

Subplot-urile permit comparații fără a suprapune serii care măsoară lucruri diferite.

fig, axs: 1 rând și 2 coloane
import numpy as np
import matplotlib.pyplot as plt

x = np.arange(1, 11)
y = 1 / np.sqrt(x)

fig, axs = plt.subplots(1, 2, figsize=(9, 4),
                        constrained_layout=True)
axs[0].plot(x, y)
axs[0].set(title="Evoluție", xlabel="Pas", ylabel="Eroare")
axs[1].hist(y, bins=5)
axs[1].set(title="Distribuție", xlabel="Eroare")
plt.show()

Argumentele sharex=True și sharey=True fac posibilă compararea pe aceeași scară. constrained_layout=True reduce suprapunerile dintre elemente.

9. Aspect, legendă, adnotări și salvare

Un grafic corect trebuie să poată fi interpretat fără să inspectăm codul care l-a generat.

Titluri, legendă, anotare și export în PNG
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(7, 4),
                       constrained_layout=True)
ax.plot([1, 2, 3, 4], [0.9, 0.7, 0.5, 0.35],
        marker="o", label="Pierdere")
ax.set(title="Învățarea modelului", xlabel="Epocă",
       ylabel="Funcția de pierdere")
ax.annotate("Minim", xy=(4, 0.35), xytext=(2.7, 0.45),
            arrowprops={"arrowstyle": "->"})
ax.legend()
ax.grid(alpha=0.25)
fig.savefig("curba_invatarii.png", dpi=180,
            bbox_inches="tight")
plt.show()
  • Folosește titluri informative, denumiri de axe și unități acolo unde este cazul.
  • Păstrează aceeași scară când compari grafice similare; evită trunchierea axei verticale la graficele cu bare.
  • Utilizează fig.savefig(...) pentru PNG/SVG/PDF; dpi controlează rezoluția exportului raster.
  • Preferă palete în care culorile pot fi distinse și fără o vedere normală a culorilor; adaugă marcatori sau stiluri de linie.

10. Seaborn: API statistic și date în format tabelar

Seaborn pornește de la Matplotlib, dar simplifică maparea coloanelor unui DataFrame la axele și caracteristicile vizuale ale graficului.

Convenția uzuală este import seaborn as sns. În funcțiile Seaborn, data primește un DataFrame, x și y numele coloanelor, iar hue poate reprezenta o categorie prin culoare. Funcțiile la nivel de axes (de exemplu sns.scatterplot) acceptă ax=; funcțiile la nivel de figure (precum sns.relplot) creează propriile figuri.

sns.scatterplot cu hue și style
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

observatii = pd.DataFrame({
    "lungime": [2.2, 2.8, 3.1, 6.1, 6.8, 7.3],
    "latime": [1.0, 1.4, 1.3, 3.2, 3.7, 3.5],
    "clasa": ["A", "A", "A", "B", "B", "B"]
})

fig, ax = plt.subplots()
sns.scatterplot(data=observatii, x="lungime", y="latime",
                hue="clasa", style="clasa", s=90, ax=ax)
ax.set_title("Caracteristici pe clase")
plt.show()

11. Seaborn pentru distribuții: histplot și kdeplot

Seaborn adaugă opțiuni rapide pentru estimarea și compararea distribuțiilor.

sns.histplot cu estimare KDE
import numpy as np
import seaborn as sns
import matplotlib.pyplot as plt

rng = np.random.default_rng(42)
valori = rng.normal(5.2, 1.35, 300)

fig, ax = plt.subplots()
sns.histplot(x=valori, bins=20, stat="density",
             kde=True, color="steelblue", ax=ax)
ax.set(xlabel="Valoare", ylabel="Densitate")
plt.show()
Ce este KDE?
Kernel density estimation reprezintă o estimare netedă a densității probabilității. Forma curbei depinde de parametrul de netezire și nu trebuie interpretată ca dovada existenței unei legi de probabilitate specifice.

12. Seaborn pentru categorii: countplot, barplot și boxplot

Graficele de categorii pot arăta atât numărul de observații, cât și o statistică agregată pentru fiecare grup.

countplot (frecvențe) vs barplot (medii)
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

date = pd.DataFrame({
    "metoda": ["A", "A", "A", "B", "B", "B"],
    "scor": [0.76, 0.79, 0.81, 0.82, 0.86, 0.89]
})

fig, axs = plt.subplots(1, 2, figsize=(9, 4))
sns.countplot(data=date, x="metoda", color="steelblue", ax=axs[0])
sns.barplot(data=date, x="metoda", y="scor",
            errorbar="sd", color="teal", ax=axs[1])
axs[0].set_title("Număr exemple")
axs[1].set_title("Media și abaterea standard")
plt.tight_layout()
plt.show()
Atenție la barele de eroare
În versiunile recente ale Seaborn, errorbar="sd" reprezintă abaterea standard; implicit, barplot poate afișa un interval de încredere pentru estimarea mediei. Nu confunda aceste cantități.

13. Pairplot și analiza relațiilor între mai multe variabile

O matrice de diagrame scatter arată rapid perechile de caracteristici și distribuțiile marginale.

sns.pairplot
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

date = pd.DataFrame({
    "inaltime": [150, 155, 160, 175, 180, 185],
    "greutate": [45, 49, 52, 67, 72, 78],
    "grupa": ["A", "A", "A", "B", "B", "B"]
})

g = sns.pairplot(data=date, vars=["inaltime", "greutate"],
                 hue="grupa", diag_kind="hist")
g.fig.suptitle("Relațiile dintre caracteristici", y=1.03)
plt.show()

Un pairplot devine greu de citit când numărul caracteristicilor este foarte mare. Selectează un subset relevant, mai ales în proiectele cu sute de atribute.

14. Heatmap și matricea corelațiilor

O hartă termică codifică valori numerice prin culori; este deosebit de utilă pentru analiza corelațiilor dintre caracteristici.

sns.heatmap pentru matricea de corelații
import numpy as np
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

rng = np.random.default_rng(4)
x = rng.normal(size=100)
date = pd.DataFrame({
    "X": x,
    "Y": 0.8 * x + rng.normal(scale=0.4, size=100),
    "Z": rng.normal(size=100)
})

fig, ax = plt.subplots()
sns.heatmap(date.corr(), annot=True, fmt=".2f",
            cmap="coolwarm", center=0, vmin=-1, vmax=1,
            ax=ax)
plt.show()
Corelație ≠ cauzalitate
Corelația Pearson evidențiază relații liniare; o corelație aproape zero nu exclude relații neliniare. O matrice de corelații nu dovedește că o caracteristică este cauza alteia.

15. FacetGrid și relplot: comparații prin panouri

Împărțirea setului de date în panouri separate este utilă când aceeași relație trebuie comparată între categorii.

sns.relplot pe categorii

date = pd.DataFrame({

16. Vizualizarea densității pentru multe puncte

Când mii de puncte se suprapun, un scatter obișnuit ascunde densitățile locale.

hexbin pentru un nor dens de puncte
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(21)
puncte = rng.multivariate_normal([0, 0],
            [[1, 0.7], [0.7, 1]], size=2500)

fig, ax = plt.subplots()
rez = ax.hexbin(puncte[:, 0], puncte[:, 1],
                gridsize=30, mincnt=1, cmap="Blues")
fig.colorbar(rez, ax=ax, label="Număr de puncte")
ax.set(xlabel="X", ylabel="Y", title="Densitate hexagonală")
plt.show()

17. Mic proiect EDA: de la tabel la concluzie

Înainte de un model de învățare automată, verifică distribuțiile, clasele și relațiile dintre caracteristici.

Descarcă setul demonstrativ observatii_viz.csv. Un flux rezonabil: (1) citește un CSV în Pandas; (2) verifică shape, head() și valorile lipsă; (3) reprezintă numărul exemplelor pe clasă; (4) inspectează histogramele caracteristicilor numerice; (5) compară perechi de caracteristici și corelații; (6) notează observații, nu doar grafice.

Șablon de analiză: adaptează coloanele și fișierul
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# Modifică numele coloanei-țintă după setul tău de date.
df = pd.read_csv("datasets/observatii_viz.csv")
print(df.shape)
print(df.isna().sum())

fig, axs = plt.subplots(1, 2, figsize=(10, 4))
sns.countplot(data=df, x="eticheta", color="steelblue", ax=axs[0])
sns.histplot(data=df, x="scor", bins=20, color="teal", ax=axs[1])
plt.tight_layout()
plt.show()
Ce verificăm înainte de concluzii?
Ordinea categoriilor, tipurile coloanelor, valorile lipsă, dimensiunea eșantionului, eventualele clase rare și regulile de prelucrare. Graficele ajută la formularea de ipoteze, dar nu înlocuiesc validarea lor.

18. Greșeli frecvente și bune practici pentru ONIA

Graficele trebuie să fie corecte, lizibile și reproductibile.

  • Nu reprezenta serii fără titlu și etichete: elevii care citesc graficul trebuie să știe ce reprezintă valorile.
  • Nu folosi sns.barplot pentru a număra exemple dacă ai nevoie de countplot — primul agregă valori numerice.
  • Nu interpreta KDE ca distribuție „adevărată”: aspectul depinde de netezire.
  • Nu compara vizual axe de valori care au scale diferite fără să menționezi diferența.
  • Verifică dacă ai valori lipsă și dacă graficele selectează aceeași populație de observații.
  • Creează grafice reproductibile: date clare, np.random.default_rng(seed) pentru simulări, export local pentru rezultate.
  • Folosește plt.close(fig) când generezi multe figuri într-un script, pentru a evita acumularea acestora în memorie.

Rezumat: Matplotlib oferă control fin prin obiectele Figure/Axes; Seaborn simplifică statisticile vizuale bazate pe DataFrame. Scopul nu este reproducerea mecanică a unor comenzi, ci selectarea graficului potrivit pentru o întrebare de analiză.

Referințe bibliografice folosite la documentare: „introduction-to-matplotlib”, „04.14-Visualization-With-Seaborn” și „matplotlib-exercises”. Graficele din lecție reprezintă date sintetice și sunt incluse în proiect; nu reprezintă rezultate reale de model.
