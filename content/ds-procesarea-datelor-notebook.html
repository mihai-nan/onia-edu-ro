Notebook: Procesarea datelor

Codul poate fi executat în JupyterLab. Aici este afișată o selecție de exemple.

Exemplul 1

Python 3 · exemplu explicat
import pandas as pd
df = pd.DataFrame({
    'vârstă': [15, 16, None, 15],
    'oraș': ['Iași', 'Cluj', 'Iași', 'Iași'],
    'scor': [82, 91, 77, 82]
})
print(df.info())
print(df.isna().sum())
print(df.select_dtypes(include='number').describe())

Exemplul 3

Python 3 · exemplu explicat
import numpy as np
from sklearn.impute import SimpleImputer
X_train = np.array([[1., 7.], [2., np.nan], [3., 11.]])
X_test = np.array([[4., np.nan]])
imp = SimpleImputer(strategy='median')
print(imp.fit_transform(X_train))
print(imp.transform(X_test))
