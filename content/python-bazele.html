1. Primii pași: variabile, tipuri și indentare

În Python, tipul este asociat valorii la momentul execuției. Nu declarăm în prealabil tipul fiecărei variabile, iar blocurile de instrucțiuni sunt delimitate prin indentare.

TipExempluCe reprezintă

float0.25Număr în virgulă mobilă, aproximativ
boolTrue, FalseValoare logică
str"ONIA"Șir Unicode de caractere
NoneTypeNoneAbsența unei valori
list, tuple[1,2], (1,2)Secvențe ordonate
dict, set{"x":1}, {1,2}Asociere cheie-valoare / valori distincte
Valori, tipuri și indentare
nume = "Ana"
varsta = 16
scor = 87.5
admis = scor >= 60
print(type(scor).__name__, type(admis).__name__)

if admis:
    print(f"{nume} a trecut pragul de calificare.")
Rezultat
float bool
Ana a trecut pragul de calificare.

Operatorul = realizează atribuirea, nu compararea. Un nume poate fi asociat ulterior unei valori de alt tip; adnotările precum varsta: int = 16 exprimă intenția și sunt utile instrumentelor de analiză statică, dar nu impun singure verificarea tipurilor la execuție.

De reținut
True și False încep cu literă mare. None este diferit de 0 și de șirul vid. Folosește nume explicite, de regulă în stilul snake_case.

3. Citirea de la tastatură și conversii

Funcția input() întoarce întotdeauna un șir de caractere. Pentru calcule, transformăm explicit datele în tipul așteptat.

Citire pe linii și valori separate prin spații
n = int(input("n = "))
a, b = map(int, input("a b = ").split())
valori = list(map(float, input("Valori: ").split()))
print(n, a + b, sum(valori))

Metoda split(), fără argument, separă după secvențe de caractere albe (spații, taburi, linii noi). Pentru fișiere sau input amplu, putem citi întregul flux și să îl despărțim în tokenuri.

Citire rapidă a întregii intrări
import sys

tokenuri = sys.stdin.read().split()
numere = [int(x) for x in tokenuri]
print(sum(numere))
Exemplu de conversie
int("15") produce 15, însă int("15.2") produce ValueError. Pentru valori reale scrise cu punct, folosește float().

4. Afișarea cu print(), sep, end și f-string

print() convertește argumentele în text și le trimite implicit către consolă. Parametrii sep și end controlează caracterele dintre valori și de la sfârșit.

Cum funcționează sep și end
print("IA", "Python", 2026)
print("IA", "Python", 2026, sep=" | ")
print("ON", end="")
print("IA")
print(*[3, 5, 8], sep=", ")
Rezultat
IA Python 2026
IA | Python | 2026
ONIA
3, 5, 8

Valorile implicite sunt sep=" " (un spațiu) și end="\n" (trecere la linia următoare). Prin print(*lista), elementele listei devin argumente separate.

f-string și formatare
nume = "Ana"
punctaj = 87.456
print(f"Elev: {nume} | scor: {punctaj:.2f}")
print(f"Procent: {0.875:.1%}")
print(f"Număr în binar: {13:b}, hexazecimal: {13:x}")
print(f"{'model':<12} | {0.932:>7.2%}")
Rezultat
Elev: Ana | scor: 87.46
Procent: 87.5%
Număr în binar: 1101, hexazecimal: d
model        |  93.20%

Un f-string este un șir precedat de f în care expresiile din acolade sunt evaluate înaintea afișării. :.2f cere două zecimale, :.1% afișează un procent, iar :<12 aliniază la stânga într-un câmp de lățime 12.

Jupyter vs. consolă
În Jupyter, ultima expresie dintr-o celulă poate fi afișată automat. Într-un fișier .py, pentru a vedea rezultatul trebuie de regulă să folosești explicit print().

5. Condiții, bucle și iterare

Instrucțiunile if, for și while sunt indispensabile pentru prelucrarea seturilor de date. Indentarea indică apartenența la bloc.

Filtrare și range()
scoruri = [54, 82, 91, 37, 66]
prag = 60
promovati = 0
for scor in scoruri:
    if scor >= prag:
        promovati += 1
print(f"Peste prag: {promovati}/{len(scoruri)}")

for i in range(2, 8, 2):
    print(i, end=" ")
Rezultat
Peste prag: 3/5
2 4 6
while, continue și testarea condiției
x = 40
pas = 0
while x > 5:
    x //= 2
    pas += 1
print(x, pas)

for x in [3, 0, 5]:
    if x == 0:
        continue
    print(30 // x)
Rezultat
5 3
10
6

range(start, stop, step) include start și exclude stop. break întrerupe bucla, iar continue trece la iterația următoare. Funcția enumerate() produce perechi (index, valoare), utile la parcurgerea listelor.

6. Definirea subprogramelor și modalități de apel

În Python, subprogramele sunt implementate prin funcții definite cu def. Ele pot primi argumente, returna rezultate și pot fi reutilizate în aplicații mai mari.

Parametri, return, apel pozițional și nominal
def acuratete(corecte, total):
    if total == 0:
        return 0.0
    return corecte / total

print(acuratete(18, 20))          # pozițional
print(acuratete(total=20, corecte=18))  # nominal
Rezultat
0.9
0.9
Valoare implicită, returnarea unui tuplu
def statistici(valori, precizie=2):
    if not valori:
        return None
    minim = min(valori)
    maxim = max(valori)
    medie = round(sum(valori) / len(valori), precizie)
    return minim, maxim, medie

lo, hi, avg = statistici([4, 9, 8], precizie=3)
print(lo, hi, avg)
Rezultat
4 9 7.0
Mod de apelSintaxăObservație
Poziționalf(3, 5)Argumentele corespund pozițiilor parametrilor
Nominalf(b=5, a=3)Asociere explicită după nume
Implicitf(3)Parametrii omiși folosesc valorile implicite
Despachetaref(*pereche)Argumentele provin dintr-o secvență
Despachetare nominalăf(**date)Argumentele provin dintr-un dicționar
Despachetarea argumentelor
def combina(a, b=1):
    return a * 10 + b

pereche = (4, 7)
argumente = {"a": 4, "b": 7}
print(combina(*pereche))
print(combina(**argumente))

Greșeală de evitat
Nu folosi o listă mutabilă ca valoare implicită dacă intenționezi una nouă la fiecare apel: preferă def f(a=None):, apoi a = [] if a is None else a. O funcție fără return explicit returnează None.

7. Liste: indexare, slicing și metode

O listă este o secvență ordonată și mutabilă. Se folosește pentru șiruri de date, caracteristici, predicții, etichete și multe alte structuri intermediare.

Indexare și felii

print(scoruri[0], scoruri[-1])
print(scoruri[1:4])
print(scoruri[::-1])
scoruri.append(20)
scoruri[1] = 9
print(scoruri)
Rezultat

[15, 7, 18, 7, 12]

List comprehension și enumerate
numere = [2, 3, 4, 5, 6]

Aliasing și copii
a = [1, 2]

8. Tupluri: secvențe nemodificabile

Tuplurile păstrează ordinea, permit indexare și slicing, dar nu permit înlocuirea unui element. Sunt potrivite pentru coordonate, perechi și rezultate multiple.

Tupluri și despachetare
punct = (3, 8)
x, y = punct
print(x + y)

scoruri = (80, 92, 73)
print(scoruri[1:])
unu = (5,)        # tuplu cu un singur element
print(type(unu).__name__)
Rezultat
11
(92, 73)
tuple

Imutabilitatea este o proprietate a tuplului ca structură: dacă un element din tuplu este, la rândul lui, o listă, acea listă poate fi modificată. Un tuplu poate fi cheie într-un dicționar numai dacă toate elementele sale sunt hashable.

9. Dicționare: asocierea dintre chei și valori

Un dicționar permite accesul la valori prin chei, nu prin poziții. Este foarte util pentru etichete, configurații, numărarea frecvențelor și agregarea datelor.

Numărarea frecvențelor
etichete = ["pisică", "câine", "pisică", "pasăre"]
frecvente = {}
for eticheta in etichete:
    frecvente[eticheta] = frecvente.get(eticheta, 0) + 1
print(frecvente)
print(frecvente.get("vulpe", 0))
Rezultat
{'pisică': 2, 'câine': 1, 'pasăre': 1}
0
Inserare, eliminare și parcurgere
rezultate = {"Ana": 93, "Mara": 88}
rezultate["Ioana"] = 95
eliminat = rezultate.pop("Mara")
for nume, punctaj in rezultate.items():
    print(nume, punctaj)
print(eliminat)
Rezultat
Ana 93
Ioana 95
88

dict.keys() oferă cheile, dict.values() valorile, iar dict.items() perechile. În Python modern, un dicționar păstrează ordinea inserării cheilor, dar nu este sortat automat. Accesul d[cheie] pentru o cheie absentă generează KeyError; get() poate evita această eroare.

10. Mulțimi (set): elemente distincte

Un set conține elemente hashable distincte și nu este o secvență indexabilă. Este potrivit pentru eliminarea duplicatelor și verificarea apartenenței.

Operații pe mulțimi
a = {1, 2, 3, 4}
b = {3, 4, 5}
print(sorted(a | b))   # reuniune
print(sorted(a & b))   # intersecție
print(sorted(a - b))   # diferență
print(sorted(a ^ b))   # diferență simetrică

identificatori = [4, 4, 9, 2, 9]
print(len(set(identificatori)))
Rezultat
[1, 2, 3, 4, 5]
[3, 4]
[1, 2]
[1, 2, 5]
3

Mulțimea vidă se creează cu set(), nu cu {} (care creează un dicționar). Metode uzuale: add(), discard(), remove(). discard(x) nu produce eroare dacă x lipsește; remove(x) produce KeyError.

Pentru sarcini de IA este esențial să poți importa, curăța și exporta date. Folosim with open(...) pentru închiderea sigură a fișierelor.

ModSemnificație
"r"Citire (fișierul trebuie să existe)
"w"Scriere: creează sau suprascrie un fișier
"a"Adaugă la sfârșitul fișierului

Date de intrare și ieșire din fișier
# date.in (exemplu):
# 4
# 7 12 9 5

with open("rezultat.out", "w", encoding="utf-8") as fout:

Parcurgerea tuturor liniilor
# O valoare numerică pe linie, număr necunoscut de linii
with open("scoruri.txt", "r", encoding="utf-8") as fin:
    scoruri = [float(linie.strip()) for linie in fin
              if linie.strip()]

with open("rezumat.txt", "w", encoding="utf-8") as fout:
    fout.write(f"Număr de scoruri: {len(scoruri)}\n")
Format CSV cu antet
import csv

# CSV: id,eticheta,scor
with open("predictii.csv", newline="", encoding="utf-8") as fin:
    cititor = csv.DictReader(fin)
    randuri = list(cititor)

with open("predictii_filtrate.csv", "w", newline="", encoding="utf-8") as fout:
    scriitor = csv.DictWriter(fout, fieldnames=["id", "eticheta", "scor"])
    scriitor.writeheader()
    for rand in randuri:

            scriitor.writerow(rand)

Format JSON

13. Exemple rezolvate cu aplicații în inteligența artificială

Combinăm elementele învățate în probleme apropiate de procesarea datelor și evaluarea modelelor.

Exemplul 1 — Acuratețea unui clasificator

Avem două liste de etichete: cele reale și cele prezise. Determinăm numărul de predicții corecte și acuratețea. Verificăm și dacă listele au aceeași lungime.

Soluție rezolvată
def evaluare_clasificare(reale, prezise):
    if len(reale) != len(prezise):
        raise ValueError("Listele trebuie să aibă aceeași lungime")
    corecte = sum(a == b for a, b in zip(reale, prezise))
    return corecte, corecte / len(reale) if reale else 0.0

reale = ["pisică", "câine", "pisică", "pasăre", "câine"]
prezise = ["pisică", "pisică", "pisică", "pasăre", "câine"]
corecte, scor = evaluare_clasificare(reale, prezise)
print(f"Predicții corecte: {corecte}; acuratețe: {scor:.1%}")
Rezultat
Predicții corecte: 4; acuratețe: 80.0%

Funcția zip() grupează elementele corespunzătoare din două iterabile. sum() poate însuma valori logice deoarece True se comportă numeric ca 1, iar False ca 0. Dacă nu am verifica dimensiunile, zip() s-ar opri la lista mai scurtă.

Exemplul 2 — Vocabularul și frecvențele unui text

Pornind de la o propoziție, normalizăm textul, construim vocabularul de cuvinte distincte și un dicționar de frecvențe.

Soluție rezolvată
text = "AI învață din date. AI folosește date!"
for semn in ".,!?:;":
    text = text.replace(semn, " ")
cuvinte = text.lower().split()
vocabular = sorted(set(cuvinte))
frecvente = {}
for cuvant in cuvinte:
    frecvente[cuvant] = frecvente.get(cuvant, 0) + 1
print(vocabular)
print(frecvente["ai"], frecvente["date"])
Rezultat
['ai', 'date', 'din', 'folosește', 'învață']
2 2

Exemplul ilustrează o preprocesare elementară; în aplicații NLP complexe trebuie tratate mai atent semnele de punctuație, cuvintele compuse și formele lexicale.
