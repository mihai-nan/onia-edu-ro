Fișiere CSV — citire, scriere și prelucrare

Un ghid de la structura fișierelor CSV până la import și export cu biblioteca standard csv și Pandas, folosind datele din notebookul Pandas furnizat.

Conținut: delimiter · antet · reader · DictReader · read_csv · to_csv
01

1. Cum este organizat un fișier CSV?

CSV înseamnă Comma-Separated Values: un format text pentru date tabelare. Delimitatorul poate fi virgula, punct și virgulă sau alt caracter, conform convenției fișierului.

Structura unui fișier, prezentată drept comentarii
# Exemplu de conținut CSV (scoruri.csv)
# elev,scor,oras
# Ana,91,Bucuresti
# Radu,87,Cluj
# "Maria, Elena",95,Iasi

Prima linie poate reprezenta antetul. Valorile care conțin separatorul, ghilimele sau linii noi se încadrează în ghilimele conform regulilor CSV. De aceea, separarea manuală folosind split(",") nu este corectă pentru toate fișierele CSV.

De reținut
CSV nu specifică automat tipuri de date: numerele, datele calendaristice și valorile booleene trebuie interpretate după citire.
02

2. Citirea cu modulul standard csv

Modulul csv este inclus în Python și permite control precis asupra delimitatorilor și câmpurilor.

Citire cu csv.reader
import csv

with open("datasets/scoruri.csv", encoding="utf-8", newline="") as fin:
    cititor = csv.reader(fin)
    antet = next(cititor)
    for rand in cititor:
        nume = rand[0]
        scor = float(rand[1])
        print(nume, scor)

Parametrul newline="" este recomandat în documentația modulului CSV pentru tratarea corectă a terminatorilor de rând. next() poate consuma prima linie, iar în corpul buclei conversia la float transformă textul numeric.

03

3. Citirea câmpurilor după nume cu DictReader

Pentru un tabel cu antet, DictReader reprezintă fiecare rând ca dicționar: numele coloanelor devin chei.

Media dintr-un CSV
import csv

suma = 0.0
numar = 0
with open("datasets/scoruri.csv", encoding="utf-8", newline="") as fin:
    for rand in csv.DictReader(fin):
        suma += float(rand["scor"])
        numar += 1

if numar:
    print(f"Media: {suma / numar:.2f}")
De reținut
Dacă un câmp lipsește sau conține text neconvertibil, apar erori. În aplicații reale, verifică explicit conținutul și tratează ValueError și eventualele valori goale.
04

4. Scrierea unui CSV

Folosește csv.writer pentru rânduri de liste și csv.DictWriter pentru rânduri reprezentate prin dicționare.

Scriere cu antet și câmpuri nominale
import csv

rezultate = [
    {"elev": "Ana", "scor": 92},
    {"elev": "Radu", "scor": 85},
]
with open("rezultate.csv", "w", encoding="utf-8", newline="") as fout:
    writer = csv.DictWriter(fout, fieldnames=["elev", "scor"])
    writer.writeheader()
    writer.writerows(rezultate)

Pentru fișierele despărțite prin ;, adaugă delimiter=";" atât la citire, cât și la scriere. Pentru anumite foi de calcul pot fi necesare și setări explicite de codificare.

05

5. CSV în Pandas: read_csv și to_csv

În analiza de date, Pandas poate încărca direct CSV într-un DataFrame; rezultatul poate fi filtrat, agregat și exportat.

Exemplu complet de import și export
import pandas as pd

# Date reale din notebookul Pandas
avocado = pd.read_csv("datasets/avocado.csv", index_col=0)
print(avocado.head(3))

medii = avocado.groupby("region", as_index=False)["AveragePrice"].mean()
medii.to_csv("preturi_medii_regiuni.csv", index=False)

read_csv suportă parametri precum sep (separator), encoding (codificare), usecols (coloane selectate), nrows (număr de rânduri) și parse_dates (interpretarea datelor calendaristice).

ArgumentRol
index_col=0Prima coloană devine index
index=False la to_csvNu exportă indexul intern
sep=";"Citește un CSV cu separator punct și virgulă
usecols=[...]Importă doar anumite coloane
parse_dates=["Date"]Interpretează o coloană drept dată calendaristică

6. Import robust și verificarea rezultatelor

Prelucrările pentru competițiile de IA trebuie să rămână reproductibile și să trateze explicit valorile invalide.

Conversie sigură și tratarea valorilor invalide
import pandas as pd

date = pd.read_csv("datasets/scoruri.csv")
date["scor"] = pd.to_numeric(date["scor"], errors="coerce")
print(date.isna().sum())
date = date.dropna(subset=["scor"])
print(date["scor"].mean())

Nu elimina automat rândurile cu probleme fără a evalua impactul. În aplicații de învățare automată, o preprocesare incorectă poate distorsiona datele și performanța modelului.
