1. Ce este Pandas?

Pandas este o bibliotecă Python pentru analiza și prelucrarea datelor tabelare, cu facilități de import/export în CSV, JSON, Excel și alte formate.

Două structuri sunt centrale: Series (o coloană, cu valori și etichete de index) și DataFrame (un tabel bidimensional cu rânduri și coloane). Un DataFrame poate conține coloane de tipuri diferite.

Explicație pas cu pas · exemplu vizual

Cum este construit un DataFrame?

În Pandas, Series este un șir de valori asociate unor etichete (index), iar DataFrame este o colecție de coloane, fiecare având propriul tip de date. Gândește-te la un tabel de observații: un rând reprezintă o observație, iar o coloană o caracteristică.

Series — o singură coloană

s = pd.Series([1.2, 1.4, 1.1]). Indexul implicit este 0, 1, 2; numele pret descrie seria.

DataFrame — mai multe coloane

pd.DataFrame({"oras": [...], "scor": [...]}). Coloana oras este text, iar scor este numerică.

indexorasscor
0București0.91
1Cluj0.88

s.mean() = (1.2 + 1.4 + 1.1) / 3 = 3.7 / 3 ≈ 1.2333
print(df["scor"].mean())  # (0.91 + 0.88 + 0.86) / 3 = 0.883333...

Ce semnifică fiecare statistică din describe()?

Înaintea oricărei analize, inspectează forma, tipurile, calitatea datelor și câteva înregistrări. Nici head(), nici tail() nu reprezintă un eșantion aleator; arată începutul și sfârșitul ordinii curente.

4. Selectarea coloanelor, loc și iloc

Selectezi o coloană printr-un nume, mai multe coloane printr-o listă, iar elementele prin loc sau iloc.

Explicație pas cu pas · exemplu vizual

loc vs. iloc — aceeași celulă, două moduri de selectare

În Pandas există două sisteme de referință: etichetele rândurilor/coloanelor (loc) și pozițiile lor de la 0 (iloc). Pentru a le compara, folosim un tabel mic cu indexuri text.

Selectează o expresie și urmărește celulele evidențiate

loc folosește numele: df.loc["E02", "scor"]. iloc folosește poziția: df.iloc[1, 1]. În slicing, limita finală este inclusă la loc în cazul etichetelor existente, dar este exclusă la iloc, la fel ca în Python.

O singură coloană

df["scor"] → Series, shape (3,).

Listă de coloane

df[["scor"]] → DataFrame, shape (3, 1).

În fișierul real avocado din proiect, indexul importat cu index_col=0 nu este unic: eticheta 0 apare de 432 de ori. De aceea avocado.loc[0, "AveragePrice"] întoarce mai multe valori, nu neapărat una singură. Pentru prima valoare după poziție folosește avocado.iloc[0]["AveragePrice"] sau avocado.iloc[0, avocado.columns.get_loc("AveragePrice")].
Selectare după nume sau poziție — fără ambiguitatea etichetelor repetate
preturi = avocado["AveragePrice"]
selectie = avocado[["AveragePrice", "Total Volume"]]
print(preturi.head(2))
print(selectie.iloc[:3, :])
print(avocado.iloc[0]["AveragePrice"])

loc folosește etichetele rândurilor și coloanelor; iloc folosește pozițiile întregi. Nu confunda indexul numeric folosit ca etichetă cu poziția elementului.

5. Filtrarea pe baza condițiilor

Condițiile se evaluează pe fiecare rând și produc o mască booleană folosită pentru selectare.

Explicație pas cu pas · exemplu vizual

De la condiție la mască, apoi la rândurile selectate

O comparație precum df["scor"] >= 8 nu produce un singur True/False. Ea compară fiecare rând și întoarce o Series booleană cu câte un rezultat pentru fiecare observație. df[masca] păstrează doar rândurile unde masca este True.

Schimbă pragul și urmărește masca booleană
8
masca = elevi["scor"] >= 8
print(masca)       # câte un True/False pentru fiecare elev
print(masca.sum()) # numărul de True (True este numărat ca 1)
print(elevi[masca]) # rândurile care îndeplinesc condiția
Condiții simultane: &

(df["region"] == "Atlanta") & (df["type"] == "organic") — ambele condiții trebuie să fie adevărate.

Condiții alternative: |

(df["year"] == 2016) | (df["year"] == 2017) — cel puțin una trebuie să fie adevărată. ~ inversează o mască.

isin(["Atlanta", "Columbus"]) verifică apartenența la o listă de valori; between(a, b) verifică încadrarea într-un interval (implicit capetele incluse). Folosește paranteze în jurul fiecărei comparații înainte de & sau |.
Filtrare pe criterii multiple
atlanta = avocado[avocado["region"] == "Atlanta"]
organic_ieftin = avocado[
    (avocado["type"] == "organic") &
    (avocado["AveragePrice"] < 1.02)
]
regiuni = avocado[avocado["region"].isin([
    "Atlanta", "Columbus", "SouthCentral"
])]
print(len(organic_ieftin), len(regiuni))
Capcană frecventă
Pentru serii Pandas folosește & și | între condiții, punând fiecare comparație între paranteze. Operatorii Python and/or nu sunt potriviți pentru combinarea element-cu-element a seriilor.

7. Sortarea și construirea de coloane noi

Sortarea poate folosi valorile unei coloane sau etichetele indexului. Coloanele noi pot fi obținute prin calcule vectorizate.

Explicație pas cu pas · exemplu vizual

Cum se schimbă ordinea rândurilor și cum apar coloane noi?

sort_values() schimbă ordinea observațiilor, nu valorile lor. Poți ordona crescător sau descrescător. sort_index() ordonează după etichetele indexului, ceea ce este diferit de sortarea după conținutul unei coloane.

Sortare interactivă după preț
ord = df.sort_values("pret", ascending=False)
df["pret_cu_tva"] = df["pret"] * 1.19  # exemplu matematic, cotă ipotetică
df["dublu_volum"] = df["volum"] * 2
# Nicio buclă explicită: calculele se aplică fiecărui rând.
Coloană derivată

avocado["Volum_mii"] = avocado["Total Volume"] / 1000. Valoarea 42 000 devine 42 — același volum exprimat în mii de unități.

Eliminare / redenumire

df.drop(columns=["temporar"]) întoarce un nou tabel; df.rename(columns={"pret": "pret_eur"}) redenumește o coloană.

O sortare sort_values(...) nu schimbă implicit tabelul original; păstrează rezultatul într-o variabilă. Indexul inițial rămâne asociat rândurilor, chiar dacă rândurile își schimbă poziția.
Sortare și transformări
ordonat = avocado.sort_values("AveragePrice", ascending=False)
cronologic = pe_date.sort_index()
avocado["Volum_mii"] = avocado["Total Volume"] / 1000
print(ordonat["AveragePrice"].head(3).tolist())

Pentru eliminarea unei coloane folosește drop(columns=[...]). Operațiile fără inplace=True întorc, de regulă, un obiect nou; este preferabil să atribui explicit rezultatul.

8. Statistici și agregări cumulative

Valorile numerice pot fi sumarizate prin minim, maxim, medie, mediană sau sumă, iar cumsum() calculează sumele cumulative.

Explicație pas cu pas · exemplu vizual

Ce înseamnă mean, median, sum, count și cumsum?

O agregare transformă mai multe valori într-un rezumat: sum() calculează totalul, mean() media, median() valoarea centrală, iar min()/max() extremele. Spre deosebire de ele, cumsum() returnează câte un rezultat la fiecare poziție.

OperațiePe [2, 5, 1, 4]Explicație
sum()122 + 5 + 1 + 4
mean()312 / 4
median()3Mijlocul valorilor sortate [1,2,4,5] → (2+4)/2
min() / max()1 / 5Extreme
count()4Câte valori nu sunt lipsă
nunique()4Câte valori distincte
cumsum()[2, 7, 8, 12]Totalul până la poziția curentă
Vizualizare: fiecare sumă cumulativă
Funcțiile de agregare pentru Series numerice ignoră implicit multe valori lipsă (skipna=True). count() numără valorile nelipsă; size numără toate rândurile, inclusiv cele cu valori lipsă. Pentru std(), Pandas folosește implicit abaterea standard a eșantionului (ddof=1).
Statistici uzuale
print(avocado["AveragePrice"].mean())
print(avocado["AveragePrice"].median())
print(avocado["Total Volume"].cumsum().head(3))

O medie cumulativă sau o sumă cumulativă exprimă istoricul până la rândul curent. Pentru serii temporale, sortează întâi după dată, astfel încât interpretarea cumulului să fie corectă.

9. Gruparea și agregarea datelor

Cu groupby() poți obține rapid statistici pentru fiecare regiune, tip de avocado sau dată.

Explicație pas cu pas · exemplu vizual

GroupBy explicat pe cinci observații

Instrucțiunea groupby() nu face un simplu filtru. Ea separă toate rândurile în grupuri după una sau mai multe coloane, calculează ceva separat în fiecare grup și apoi reunește rezultatele.

regiunetippreț
Aorganic4
Aconventional2
Borganic3
Bconventional5
Aorganic6
Split → Apply → Combine (selectează agregarea)
pret_pe_regiune = df.groupby("regiune")["pret"].mean()
# A: (4 + 2 + 6) / 3 = 4
# B: (3 + 5) / 2 = 4
statistici = df.groupby("regiune")["pret"].agg(["count", "mean", "max"])
Dacă grupurile au mărimi diferite, media mediilor grupurilor nu este în general media tuturor observațiilor. Pentru media globală trebuie luat în calcul și numărul de observații din fiecare grup. Agregarea fără ponderare poate schimba concluzia.
GroupBy pe una sau mai multe coloane
medii = avocado.groupby("region")["AveragePrice"].mean()
volume = avocado.groupby(["region", "type"])["Total Volume"].sum()
statistici = avocado.groupby("region")["AveragePrice"].agg(
    ["count", "mean", "median", "max"])
print(medii.head(3))

O grupare urmează logica split → apply → combine: datele sunt despărțite în grupuri, asupra fiecărui grup se calculează o statistică, apoi rezultatele sunt reunite. Este o operație centrală în analiza exploratorie.

10. Vizualizări în Pandas

Pandas poate folosi Matplotlib pentru grafice cu bare, linii, histograme și diagrame de dispersie.

Explicație pas cu pas · exemplu vizual

Cum aleg tipul de grafic și cum interpretez axele?

Un grafic corect are cel puțin o variabilă pe fiecare axă, o unitate de măsură și un tip potrivit scopului. Pandas folosește Matplotlib pentru multe dintre metodele .plot(); în notebook trebuie să ai disponibilă această bibliotecă.

bar — compararea categoriilor

Axa X: regiuni; axa Y: volumul total. Compari mărimi agregate între categorii, nu fiecare rând din fișier.

scatter — relația între două variabile

Un punct = o observație cu două coordonate: (volum, preț). Poți observa asocieri sau valori extreme, nu deduce automat cauzalitate.

line — evoluția în timp

Axa X: data; axa Y: prețul mediu. Sortează cronologic și agregă mai întâi dacă există mai multe rânduri în aceeași dată.

hist — distribuție numerică

Axa X: intervale de preț; axa Y: câte observații cad în fiecare interval. Nu reprezintă exact un grafic cu bare al categoriilor.

Aceleași idei, reprezentate prin grafice diferite
df.groupby("regiune")["volum"].sum().plot(kind="bar")
df.sort_values("Date").plot(x="Date", y="pret", kind="line")
df["pret"].plot(kind="hist", bins=5)
df.plot(x="volum", y="pret", kind="scatter")
Un scatter cu multe puncte se poate suprapune: încearcă transparență alpha=0.3. Graficele originale din notebook, păstrate mai jos, folosesc datele avocado și trebuie interpretate ținând cont de numărul mare de observații.
Grafice cu bare și scatter

11. Medii mobile și serii temporale

O medie mobilă atenuează fluctuațiile și evidențiază tendința unei serii; fereastra stabilește câte observații intră în calcul.

Explicație pas cu pas · exemplu vizual

Media mobilă: vezi exact ce valori intră în calcul

Media mobilă cu fereastra w calculează, la fiecare poziție, media celor mai recente w observații (incluzând observația curentă). Nu este media întregului set, ci o statistică locală care se deplasează odată cu fereastra.

Fereastra evidențiată se deplasează pe seria [2, 4, 6, 8, 10]
pret = pd.Series([2, 4, 6, 8, 10])
print(pret.rolling(window=3).mean())
# NaN, NaN, 4.0, 6.0, 8.0
print(pret.rolling(window=3, min_periods=1).mean())
# 2.0, 3.0, 4.0, 6.0, 8.0
Important: rolling(window=14) în exemplul avocado înseamnă 14 observații, nu automat 14 zile. Pentru seria din proiect, filtrată pe Atlanta și un singur tip, înregistrările sunt în mod obișnuit săptămânale; sortează după dată înainte de mediere. Pentru intervale calendaristice pot fi folosite ferestre de tip rolling("14D") pe un index temporal potrivit.
Fereastră mobilă de 14 observații
avocado["Date"] = pd.to_datetime(avocado["Date"])
atlanta = avocado[
    (avocado["region"] == "Atlanta") &
    (avocado["type"] == "conventional")
].sort_values("Date")
atlanta["medie_mobila_14"] = (
    atlanta["AveragePrice"].rolling(window=14).mean()
)
De reținut
Începutul unei serii cu rolling(14) are implicit 13 valori NaN, fiindcă nu există încă suficiente observații pentru o fereastră completă. Poți controla acest comportament prin min_periods.

12. Identificarea și tratarea valorilor lipsă

Datele reale pot avea celule necunoscute. Pandas reprezintă frecvent aceste valori prin NaN sau pd.NA, în funcție de tip.

Explicație pas cu pas · exemplu vizual

NaN nu este 0: cum se construiește masca de lipsuri?

O valoare lipsă nu înseamnă zero. Zero poate fi o măsurătoare validă, pe când NaN sau pd.NA semnalează că informația nu este disponibilă. Alegerea tratării poate modifica mediile, modelele și concluziile.

Două valori cunoscute și una lipsă
df = pd.DataFrame({"elev": ["Ana", "Bogdan", "Cora"],
                   "nota": [8.0, float("nan"), 10.0]})
print(df["nota"].isna())   # False, True, False
print(df["nota"].isna().sum()) # 1
print(df["nota"].mean())   # (8 + 10) / 2 = 9
df_completat = df.fillna({"nota": 9.0})
dropna()

Elimină rândurile care conțin valori lipsă (implicit, oricare dintre coloane). Poate reduce setul și introduce bias.

fillna()

Înlocuiește lipsurile cu o valoare justificată (mediană, constantă de domeniu etc.); valoarea înlocuită nu este o observație reală.

Fișierul avocado furnizat în proiect are 0 valori lipsă detectate prin isna() în coloanele citite. Diagrama folosește intenționat un set demonstrativ cu o valoare lipsă pentru a explica procedeul.
Valori lipsă: isna, dropna, fillna
lipsa = avocado.isna().sum()
print(lipsa[lipsa > 0])
fara_lipsa = avocado.dropna()
completat = avocado.fillna({"AveragePrice": 0})

isna() produce o mască booleană. Prin isna().sum() obții numărul de valori lipsă per coloană. Eliminarea sau completarea trebuie justificată în funcție de semnificația datelor: înlocuirea arbitrară cu zero poate introduce erori statistice.

13. Codificarea caracteristicilor categoriale

Modelele de machine learning folosesc în general reprezentări numerice; de aceea, valorile de tip categorie trebuie codificate.

One-hot encoding, de ce și cum?

Categoria organic nu este numerică. Dacă atribuim codurile 0 și 1 unor categorii fără ordine naturală, unele modele le pot interpreta greșit ca având o relație numerică. One-hot encoding creează indicatori separați de tip 0/1.

dtype=int produce indicatori 0/1; fără el, anumite versiuni Pandas generează implicit valori booleene. La evaluarea unui model, transformările trebuie ajustate pe datele de antrenare și aplicate consecvent datelor noi; coloanele rezultate trebuie aliniate între antrenare și test.
