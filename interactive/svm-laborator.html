De ce o clasificare corectă poate primi pierdere nenulă?

Mișcă scorul și eticheta reală. Afișăm marginea semnată y·f(x), clasificarea și max(0, 1−y·f(x)).

Calculează singur

Trei situații: y·f ≥ 1 → pierdere zero; 0 < y·f < 1 → clasă corectă, margine încălcată; y·f < 0 → clasă greșită.

Cum folosești acest laborator

În primul experiment selectează un set simplu și observă că dreapta poate separa clasele. Alege apoi „Semicercuri” și compară kernelurile linear și RBF. Crește gamma până când frontiera devine foarte neregulată și discută riscul de overfitting. Modifică C și observă numărul de vectori suport.

În al doilea experiment parcurge cele trei modele pereche și calculează manual voturile. În al treilea observă că o predicție corectă, dar prea aproape de frontieră, poate avea totuși pierdere hinge pozitivă.

Acesta este un simulator educațional, cu optimizare numerică simplificată și date sintetice. Pentru scoruri și modelare de concurs recomandăm implementările scikit-learn, validare separată și scalare corectă.
