Investigatorul expresiilor

Modifică numerele și urmărește diferențele dintre împărțirea obișnuită, împărțirea cu //, rest și comparații.

În Python, a // b este rotunjire în jos, iar a % b respectă relația a == (a // b) * b + a % b, pentru b != 0. La b = 0, aceste împărțiri produc ZeroDivisionError.

Ce elemente selectează o felie?
